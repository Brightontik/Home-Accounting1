# 🏠 Домашняя Бухгалтерия
Полноценная система для управления личными финансами с многовалютностью, бюджетированием, инвестициями и интеграцией с Telegram ботом.

## 🚀 Функционал
### 💰 Управление финансами
- Учет доходов и расходов
- Многопользовательский режим
- Переводы между пользователями
- Управление бюджетом с план/факт анализом
### 💎 Инвестиции
- Учет инвестиционных активов
- Отслеживание стоимости активов
- Автоматическое пополнение активов (регламентное задание)
- Обороты по активам
### 💱 Многовалютность
- Неограниченное количество валют
- Автоматическая загрузка курсов из ЦБ РФ
- Конвертация валют в реальном времени
- Учет остатков в разрезе валют
- Операции обмена валют (покупка/продажа/изъятие/пополнение)
### 📊 Бюджетирование
- Планирование бюджета на месяц
- Обязательные траты
- Распределение по категориям (фиксированная сумма или процент)
- Автоматический расчет остатка
- Сравнение плана и факта
### 📈 Аналитика
- **3 интерактивных дашборда:**
  - Общий дашборд
  - План/факт бюджета
  - Дашборд капитала
- **4 отчета на СКД:**
  - Остатки по валютам
  - Отчет по расходам
  - Состояние активов
  - Тестовый отчет

## 🛠️ Технологии
- **Платформа:** 1С:Предприятие 8.3
- **Интерфейс:** Управляемые формы
- **Ядро:** Библиотека стандартных подсистем (БСП)
  - Перенесено из конфигурации "1С:Бухгалтерия учебная"
- **HTTP-запросы:** Интеграция с внешними API
- **СКД:** Система компоновки данных для отчетов
- **Блокировки:** Исключительные блокировки для нумерации

## 🏗️ Архитектура
### Модули конфигурации
**Серверные модули:**
- `ДБ_ОбщегоНазначенияСервер` — бизнес-логика конфигурации
- `БюджетПланированиеСервер` — расчет планов и бюджетов
- `ВыгрузкаИзЦБКурса` — загрузка курсов валют
- `ЗаполнитьПоАктиву` — заполнение документов данными активов
- `АвтоПополнениеАктива` — автоматическое пополнение активов
**Переопределяемые модули:**
- `ДБ_ДокументыПереопределяемый` — расширение логики документов
- `ДБ_Заглушки` — заглушки для расширения
**Клиентские модули:**
- `ДлительныеОперацииКлиент` — длительные операции на клиенте
- `ОбщегоНазначенияКлиент` — общие функции БСП
### Принципы архитектуры
- ✅ Разделение на клиентские/серверные модули
- ✅ Переопределяемые модули для расширяемости
- ✅ Единая централизованная нумерация документов
- ✅ Использование регистров накопления для бизнес-логики
- ✅ Валидация данных на уровне сервера
- ✅ Централизованная обработка ошибок

## 🔗 Интеграции
### Telegram Бот
**Синхронизация пользователей:**
- Справочник "Пользователи" связан с пользователями ИБ
- Реквизит `ТелеграмID` для связи с Telegram
- Реквизит `ИдентификаторПользователяИБ` для синхронизации
- Управление правами доступа через табличную часть "Роли"
**Возможности (архитектура готова):**
- Отправка уведомлений в Telegram
- Управление финансами через бота
- Получение отчетов в чат
### Центробанк России
- Загрузка курсов валют с сайта ЦБ РФ
- HTTPS соединение с защитой OpenSSL
- Парсинг XML ответа
- Запись курсов в регистр сведений
- Регламентное задание для автоматической загрузки
### Банки
- Загрузка выписок из банков
- Обработка банковских файлов

## 📦 Метаданные
### Документы (7)
- `Доход` — учет доходов
- `Расход` — учет расходов
- `Перевод` — переводы между пользователями
- `ПриобретениеАктива` — покупка активов
- `ИзменениеСтоимостиАктива` — изменение стоимости активов
- `ОбменВалюты` — операции обмена валют
- `ПланБюджетаМесяца` — план бюджета на месяц
### Справочники (5+)
- `Пользователи` — пользователи системы с ролями и Telegram ID
- `Валюты` — справочник валют
- `Категории` — категории расходов с лимитами
- `Активы` — инвестиционные активы
- `БазаЗнаний` — база знаний с вложенными файлами
### Регистры накопления (6)
- `ОстаткиДенег` — остатки в рублях
- `ОстаткиВалюты` — остатки в разрезе валют
- `ОстаткиАктивов` — остатки активов
- `ОборотыАктивов` — обороты по активам
- `ОборотыВалюты` — обороты по валютам
- `ОборотыПоКатегориям` — обороты по категориям расходов
### Регистры сведений
- `КурсыВалют` — курсы валют ЦБ РФ
### Обработки (7)
- `ТестыФункцийИПроцедур` — unit-тесты
- `ЗагрузкаКурсаВалют` — загрузка курсов из ЦБ РФ
- `ЗагрузкаИзБанка` — загрузка из банков
- `Дашборд` — общий дашборд
- `ДашбордПланФактБюджета` — план/факт бюджета
- `ДашбортКапитал` — дашборд капитала
- `СЛ_Мониторинг` — мониторинг
### Отчеты (4)
- `ОтчётОстаткиВалюты` — остатки по валютам
- `ОтчётПоРасходамСКД` — расходы по категориям
- `ОтчётСостояниеАктивовСКД` — состояние активов
- `Тестовый` — тестовый отчет
### Планы видов характеристик
- `СЛ_НастройкиМониторинга` — настройки мониторинга

## 📥 Установка
### Требования
- Платформа 1С:Предприятие 8.3.18+
- Windows/Linux сервер 1С
- СУБД (PostgreSQL, MSSQL)
### Установка из CF файла
1. Создайте новую информационную базу
2. Загрузите конфигурацию из файла `ДомашняяБухгалтерия.cf`
3. Заполните справочники:
   - Валюты (RUB, USD, EUR)
   - Категории расходов
   - Активы (если планируете инвестировать)
4. Создайте пользователей в справочнике "Пользователи"
5. Настройте параметры (курсы валют загружаются автоматически)
### Первичная настройка
1. Создайте пользователей с ролями доступа
2. Заполните справочник "Валюты"
3. Создайте категории расходов с лимитами
4. Настройте регламентное задание для загрузки курсов валют
5. При необходимости подключите Telegram бота
